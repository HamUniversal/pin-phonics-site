# 🅿📘 Pin Phonics

**Gamified reading for ages 3–9.** A–Z pure sounds, 100 phonics games, built-in RTI
differentiation, bilingual (English / Spanish), zero prep.

> **Live site:** https://pinphonics.com (once DNS is pointed — see

## 🚀 CI/CD — auto-deploy on every push

```
edit updated.html
       │
       ▼
  git push origin main
       │
       ▼
┌─────────────────────────────────────────────────────────┐
│  GitHub Actions  (.github/workflows/ci.yml)             │
│                                                         │
│  1. build.py        → pinphonics-site/index.html        │
│  2. final_check.py  → 38 assertions                     │
│  3. serve.py smoke  → GET /, POST /api/signup           │
│  4. upload-artifact → pinphonics-site (retained 30 d)   │
│                                                         │
│  push to main ─┬─▶ deploy-netlify  (if secrets set)    │
│                └─▶ deploy-pages    (fallback, no secrets)│
└─────────────────────────────────────────────────────────┘
       │
       ▼
  live site updates in ~1 minute
```

The pipeline runs on **every push to `main`** and on every pull request (PRs run
build + tests but do **not** deploy). A manual re-run is available from the
Actions tab (`workflow_dispatch`).

### One-time setup (≈10 minutes)

1. **Create the repo** at github.com/new — name it `pin-phonics-site`, leave it
   empty (no README / LICENSE / .gitignore).

2. **Push this code:**

   ```bash
   cd /path/to/this/folder
   git init
   git add .
   git commit -m "Initial commit: Pin Phonics site + deploy pipeline"
   git branch -M main
   git remote add origin https://github.com/<YOU>/pin-phonics-site.git
   git push -u origin main
   ```

3. **Connect Netlify** — *Sites → Import from Git →* pick the repo.
   Build command: `python3 build.py` · Publish dir: `pinphonics-site`.

4. **Add two secrets** in *GitHub → Settings → Secrets and variables → Actions*:

   | Secret | Where to get it |
   |---|---|
   | `NETLIFY_AUTH_TOKEN` | Netlify → User settings → Applications → new token |
   | `NETLIFY_SITE_ID` | Netlify site → Site settings → General → Site ID |

5. **Done.** Every `git push` now deploys in ~1 minute.

> 💡 **No secrets? No problem.** If the two Netlify secrets aren't set, the
> workflow automatically falls back to **GitHub Pages** and you get a live URL
> at `https://<user>.github.io/pin-phonics-site/` for free. Add the secrets
> later to switch to Netlify + your custom domain.

Full walkthrough: **[`GITHUB_QUICKSTART.md`](./GITHUB_QUICKSTART.md)**

## 🛠 Daily workflow

```bash
# 1. Edit the source (this is the only file you normally touch)
$EDITOR updated.html

# 2. Build + verify locally (optional — CI does it too)
python3 build.py && python3 final_check.py

# 3. Commit + push → auto-deploy
git add updated.html
git commit -m "Add: new hero copy"
git push
```

That's it. Within ~1 minute the live site reflects your change.

### Working with the backend (email capture + handbook checkout)

```bash
cp config.example.js config.js       # gitignored — never commit real keys
$EDITOR config.js                    # paste Mailchimp + Gumroad/Stripe keys
python3 serve.py                     # http://127.0.0.1:4173 (serves config.js + /api/signup)
```

In production, set the same values as **GitHub Actions secrets** (see
`config.example.js` for the full list). `config.js` itself stays out of git.

## 🔒 Security notes

- `config.js` is gitignored — real keys are **never** committed.
- The site uses **public-safe endpoints only** (Mailchimp embedded-form URL, no
  secret API keys in the browser).
- For production email capture behind a server, use `server.js` (keys stay
  server-side via GitHub Actions secrets).
